# Milestone 7: Final Presentation

Milestone 7 presents the work completed in the earlier milestones. No new model
was trained for the slides.

The presentation gives extra space to the EDA because it explains why the two
datasets required different preparation. It then covers the baseline models,
tuning, SHAP findings, the OULAD time-window extension, validation, and the
recommended pilot use.
