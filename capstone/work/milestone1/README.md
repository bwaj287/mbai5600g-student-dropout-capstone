# Milestone 1: Project Proposal

Milestone 1 established the original project idea: use machine learning to
identify students who may drop out and provide an interpretable warning for
student-support staff.

## Work Completed

- Defined the higher-education retention problem.
- Proposed the UCI student dropout dataset as the starting dataset.
- Selected Logistic Regression, Decision Tree, Random Forest, and XGBoost as
  possible model families.
- Included SHAP because a risk score alone would not explain why a student was
  flagged.
- Limited the scope to methods that could run on a personal computer.

At this point the proposal was still a one-dataset prediction project. The
OULAD comparison and temporal analysis were added after the literature review
and instructor feedback.
