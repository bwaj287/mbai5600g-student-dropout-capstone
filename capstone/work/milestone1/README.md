# Milestone 1

This folder contains the first milestone of the capstone project.

## Milestone 1 Goal

Milestone 1 was the project-selection and proposal stage.

The purpose of this milestone was to:

- choose a clear capstone problem
- define the business value of the project
- propose an achievable analytical workflow for the term

## What We Did

### Step 1: Defined the problem

- Chose student dropout prediction in higher education as the project topic.
- Framed the business problem as an early-warning system for identifying at-risk students before intervention becomes too late.

### Step 2: Defined the initial modeling idea

- Planned to predict three student outcomes:
  - `Dropout`
  - `Enrolled`
  - `Graduate`
- Identified standard machine learning models as the first modeling direction:
  - logistic regression
  - decision tree
  - random forest
  - XGBoost

### Step 3: Added explainability to the original design

- Included SHAP as the main explainable AI method.
- Positioned explainability as necessary for helping educators understand why a student is being flagged as high risk.

### Step 4: Chose the original dataset plan

- Identified the `UCI Predict Students' Dropout and Academic Success` dataset as the primary planned dataset at this stage.
- Kept the scope realistic for Python, Scikit-learn, and laptop or Google Colab execution.

## Why Milestone 1 Matters

Milestone 1 established the initial capstone scope:

- a practical higher-education attrition problem
- an interpretable machine learning direction
- a feasible academic-term project plan

It was still mostly a single-dataset project at this stage. The later milestones made the project stronger by expanding it into a reproduction-and-cross-dataset design.
