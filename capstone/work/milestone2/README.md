# Milestone 2: Literature Review

Milestone 2 reviewed prior work on student performance prediction, dropout
prediction, and explainable AI in education.

## Work Completed

- Selected Islam et al. (2025) as the base paper.
- Identified UCI as the reproduction dataset.
- Added OULAD because it includes assessment and online learning behavior.
- Changed the project from a single model exercise to a comparison of two
  educational settings.
- Defined the initial research questions around model performance,
  explanation differences, and early-warning timing.

The literature showed that XGBoost, Random Forest, SHAP, and student outcome
datasets are already widely used. Our later work therefore focused more on the
timing of OULAD warnings and on differences between feature families.
