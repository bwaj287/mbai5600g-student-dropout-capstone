# Code Sample Notes

This folder contains sample notebooks and datasets used to study the professor's instructional coding style for the capstone.

## Files

- `Feature Reduction using GA.ipynb`
- `PCA.ipynb`
- `T-SNE.ipynb`
- `sample_data.csv`
- `Housing.csv`

## Observed Style Characteristics

- Notebook-first workflow with explanatory Markdown before code
- Straightforward imports using common teaching libraries such as `pandas`, `numpy`, `matplotlib`, `seaborn`, and `scikit-learn`
- Step-by-step data loading, preprocessing, modeling, and printing of results
- Limited abstraction and minimal engineering overhead
- Use of comments and section dividers to clarify the purpose of each code block
- Focus on clarity, interpretation, and visual explanation rather than production optimization

These samples are being used as a reference when developing later milestone code for this project.
