# Local Reference Materials

This folder exists in the public repository as a placeholder only.

The original local `material/` directory contains private course readings, PDF articles, and ZIP resources used for background study during the capstone. Those files were intentionally excluded from the public GitHub repository.

The exception is `code sample/`, which has been included because it contains sample notebooks and datasets used to study the professor's instructional coding style.

The excluded reading files are not required to understand the current milestone documents in `capstone/work/`.
